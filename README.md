# IPSE 3D Bounce Ball

IPSE 동아리 2023 세미나 프로젝트로 만든 Unity 3D 바운스볼 게임입니다.
공은 바닥에 닿을 때마다 자동으로 튀어 오르고, 스테이지의 별을 모두 먹으면 다음 스테이지로 넘어갑니다.

## 구성

| 폴더 | 내용 |
| --- | --- |
| `IPSE 3D Bounce Ball/` | **메인 Unity 프로젝트** (Unity 2021.3.14f1) |
| `My project/` | 초기 프로토타입 |
| `IPSE_Semina/` | 세미나 실습용 프로젝트 |
| `3D Model/`, `Image/`, `Sound/` | 블록 모델(.blend/.fbx), UI 이미지, 효과음 원본 |

## 조작

- WASD: 이동 (카메라 방향 기준), 마우스: 시점 회전
- Q: 일시정지, R: 계속하기

블록: 점프 블록(2배 점프) / 한 번 밟으면 사라지는 블록 / 비행 블록(앞으로 날아감, 부딪히거나 방향키를 누르면 멈춤)

## 2026 버그 수정

| 증상 | 원인 / 수정 |
| --- | --- |
| 플레이어 빌드 실패 | 런타임 스크립트에 `UnityEditor.*` using → 제거 |
| 2스테이지에서 떨어지거나 Retry하면 1스테이지로 돌아감, 2스테이지 클리어 시 무한 반복 | 모든 씬의 `stageNumber`가 1로 저장됨 → 현재 씬의 빌드 순서로 계산, 마지막 스테이지 클리어 시 스테이지 선택 화면으로 |
| 스테이지 선택 화면에서 2스테이지는 잠겨 있고 3스테이지가 열려 있음, 진행도 저장 안 됨 | 한 번도 채워지지 않는 배열을 비교 → 클리어 기록을 PlayerPrefs에 저장하고 그 기준으로 해금 |
| 잠긴 스테이지 / 없는 스테이지 버튼을 누르면 에러 | 해금되고 씬이 존재할 때만 이동 |
| 메인 메뉴에서 매 프레임 NullReferenceException | Ball이 없는 씬에서도 스테이지 클리어 검사 → 스테이지 씬에서만 검사 |
| 비행 블록을 밟으면 공중에 영원히 떠 있음 | 비행 상태가 해제되지 않음 → 부딪히거나 방향키를 누르면 해제, 비행 속도가 MaxSpeed로 잘리던 문제 수정 |
| 블록에서 가끔 비정상적으로 높이 튐, 튀는 높이가 매번 다름 | 접촉점 개수만큼 힘이 중복 적용 / 낙하 속도가 남은 채 힘을 더함 → 1회만, 세로 속도 초기화 후 튕김 |
| Q를 누르고 있으면 효과음 반복, 일시정지 버튼이 가끔 안 보임 | 스크립트가 3개 오브젝트에 붙어 모두 키 처리 + `GetKey` → PauseUI에서만 `GetKeyDown` 처리 |
| 계속하기(R) 후 마우스 커서가 창 밖으로 나감 / 스테이지 선택 화면에서 커서가 잠김 | 커서 잠금 상태 복구 |
| 씬 이동 후 버튼 소리에서 MissingReferenceException | 곧 삭제될 중복 AudioManager를 참조 → 싱글톤 `AudioManager.Instance` 사용 |
| 카메라가 바닥 밑으로 들어감, 화면 떨림 | 상하 회전 각도 제한, `LateUpdate`에서 카메라 이동 |
| 카메라를 위로 올리면 앞뒤 이동이 느려짐 | 카메라의 수평 회전만 이동 방향에 사용 |
| 별이 프레임레이트에 따라 위아래로 점점 밀림 | 시작 위치 기준으로 흔들림 계산 |
| GitHub에서 한글 주석 깨짐 | 스크립트 인코딩 EUC-KR → UTF-8 |
